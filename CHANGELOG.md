# Changelog

## 1.0.3 [2026-07-28]

### Added

- Added `syncFromInertia` helper for Inertia.js integration, enabling runtime translation updates without a frontend rebuild.

## 1.0.2 [2026-02-05]

### Added

- Added `linkify` helper to parse `[text]` placeholders into HTML anchor tags.

### Fixed

- Improved regex to avoid matching substrings.

## 1.0.1 [2026-02-05]

### Added

- Added support for Laravel's pluralization formats (pipe-separated and interval notation).
- Added Vite virtual module plugin for loading JSON translation files.
- Added README.

## 1.0.0 [2026-02-05]

First release.
